# 文本解析

机场运行情况、通告和语音模板支持以下规则。文档保留英文读音示例，避免把“汉化操作说明”误当作“改变航空通话语言”。

| 类型 | 输入示例 | 语音文本效果 |
| --- | --- | --- |
| 滑行道 | `TWY E16`，也支持 `TWYS` | TAXIWAY ECHO SIXTEEN |
| 跑道 | `RWY 25R`，也支持 RWYS / RUNWAY / RUNWAYS | RUNWAY TWO FIVE RIGHT |
| 仅跑道号 | `^25R` | TWO FIVE RIGHT |
| 成组数字 | `*5058` 或 `{5058}` | FIVE THOUSAND AND FIFTY-EIGHT |
| 负数 | `*-8` | MINUS EIGHT |
| 机场名称 | `+KLAX` | 从机场数据库展开机场名称 |
| 导航台名称 | `+GBN` | 从导航数据库展开为 GILA BEND |
| 缩略语 | `@RNAV` | 按席位定义的 Text / Voice 字段替换 |

输入 `@` 会显示可用缩略语自动补全菜单，详见[自定义缩略语](atis-configuration/contractions.md)。数据库中不存在的机场或导航台无法凭空补出名称。

## 编辑器中的预览

点状下划线表示发音与显示文本不同，悬停可查看展开后的语音文本。它只是预览，不写入文字 ATIS。

## 语言说明

中文内容可以作为模板和文本编辑，但所选合成服务或 WAV 包必须能处理对应语言。英文缩略语表、数字读法和英文音色不会因界面汉化而自动变成中文播报。
