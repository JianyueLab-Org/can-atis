# ATIS 配置

在主窗口打开 **ATIS Configuration**，先选择左侧席位，再编辑各标签页。

| 标签页 | 内容 |
| --- | --- |
| [General](atis-configuration/general.md) | 频率、ATIS 类型、字母范围、语音和 IDS |
| [Presets](atis-configuration/presets.md) | 预设管理、模板、外部生成器、D-ATIS 处理 |
| [Formatting](atis-configuration/formatting.md) | 各项气象和结束语的文字 / 语音格式 |
| [Contractions](atis-configuration/contractions.md) | 缩略语与发音替换 |
| [Sandbox](atis-configuration/sandbox.md) | 不上线生成并试听 ATIS |

**Apply** 应用当前修改，**Save & Close** 保存并关闭，**Cancel** 取消未应用内容。修改常规、预设或格式并保存可能使已在线席位断开，之后需检查输出再上线。

底部 **Manage Voice Packs** 打开[语音包管理](atis-configuration/voice-packs.md)，无需先选择席位。
