# 客户端使用指南

本节介绍 ATIS for CAN 的日常使用。建议先理解[配置文件、席位与预设](concepts.md)的关系，再进行配置。

## 常用操作路线

| 目标 | 对应章节 |
| --- | --- |
| 导入机场配置 | [配置文件](profiles.md) |
| 登录与音频选项 | [用户设置](user-settings.md) |
| 发布、更新 ATIS | [主窗口](main-window.md)、[ATIS 席位](atis-station.md) |
| 设置运行跑道、进近与通告 | [机场运行情况](airport-conditions.md)、[航行通告](notams.md) |
| 修改播报模板 | [预设](atis-configuration/presets.md)、[格式设置](atis-configuration/formatting.md) |
| 调整发音 | [文本解析](text-parsing.md)、[缩略语](atis-configuration/contractions.md) |
| 人工录制 / WAV 拼接 | [人工录音](voice-record-atis.md)、[语音包](atis-configuration/voice-packs.md) |
| 不上线先测试 | [沙盒](atis-configuration/sandbox.md) |
| 对接外部工具 | [WebSocket API](websockets.md) |

涉及跨用户共享、外部数字情报与语音服务的功能，应结合每章中的 CAN 说明阅读。
