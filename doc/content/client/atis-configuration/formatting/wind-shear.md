# 风切变

在非 FAA 席位的预设中使用 `[WS]`，处理 `WS R04R` 或 `WS ALL RWY`。

| 情形 | 默认文字 | 默认语音 |
| --- | --- | --- |
| 指定跑道 | `WS R{Runway}` | `Wind Shear Runway {Runway}` |
| 全部跑道 | `WS ALL RWY` | `Wind Shear All Runways` |

`{Runway}` 只用于指定跑道模板，注意大小写。文字保留 04R，语音逐位并读出 LEFT / RIGHT / CENTER，例如 ZERO FOUR RIGHT。两类情形的文字和语音可分别修改。
