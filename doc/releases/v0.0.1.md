# CAN ATIS 0.0.1 预发布（C#）

这是 C# 桌面客户端新版本序列的首个预发布版本。

## 下载与运行

- Windows x64：下载 `atis-for-can.exe`，直接运行。
- 发布附件只包含 C# 桌面客户端的单文件程序；已内置 .NET 运行时、必要的 Python 语音桥接组件、Opus、原生音频库和机场数据，无需单独安装 .NET 或 Python。
- 首次运行会自动解压必要的运行组件。

## 更新内容

- 接入 can-client-ui 的深色紧凑 ATIS 界面，更新中文导航、设置和配置页面。
- 席位列表支持左侧/顶部切换，设置持久化。
- 移除登录页的管制等级选择，使用 CAN ID、网络密码和姓名登录；FSD 以 ATIS 台站类型连接。
- 当前席位底部显示 FSD 连接状态与 TCP RTT、语音连接状态与 TCP/UDP 传输方式及心跳 RTT。
- 语音保持连接并循环广播，复用 Python CAN 客户端的传输状态与延迟统计。
- 日志保存在程序旁边的 `Logs` 文件夹，按日分文件，单文件 20 MB 后分卷，保留最近 30 个文件；工具栏可直接打开日志目录。

## 验证

- 289 项 .NET 测试及 3 项 Python 语音状态测试通过。
- 单文件程序自检通过，验证内置机场数据、原生音频和语音进程启动。
- 本次未使用真实账号验证线上 FSD/Mumble 登录及实际音频播报。
