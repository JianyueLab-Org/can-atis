# CAN ATIS 1.0.0 正式版（C#）

这是 C# 桌面客户端的首个正式发布版本。

## 更新内容

- 接入 can-client-ui 的深色紧凑 ATIS 界面，更新中文导航、设置和配置页面。
- 席位列表支持左侧/顶部切换，设置持久化。
- 移除登录页的管制等级选择，使用 CAN ID、网络密码和姓名登录；FSD 以 ATIS 台站类型连接。
- 当前席位底部显示 FSD 连接状态与 TCP RTT、语音连接状态与 TCP/UDP 传输方式及心跳 RTT。
- 语音保持连接并循环广播，复用 Python CAN 客户端的传输状态与延迟统计。
- 修复网络播音进错频道：客户端按 Hz 传频率，语音进程原先按 MHz 解析，会进到 `FREQ_127800000000` 这样没人收听的频道；现在 Hz 和 MHz 都映射到 `FREQ_127800`。
- 语音发送进程改由 [can-audio](https://github.com/JianyueLab-Org/can-audio) 统一维护，使用与其他 CAN 客户端相同的 `mumblecompat`（语音服务器证书指纹校验、发送缓冲重试）。
- 日志保存在程序旁边的 `Logs` 文件夹，按日分文件，单文件 20 MB 后分卷，保留最近 30 个文件；工具栏可直接打开日志目录。
- 由 GitHub Actions 自动编译和发布。

## 验证

- .NET 单元测试与 can-audio atis-worker 测试在发布流程中通过。
- 单文件程序自检通过，验证内置机场数据、原生音频和语音进程启动。
- 本次未使用真实账号验证线上 FSD/Mumble 登录及实际音频播报。
