    过渡高度层

    非 FAA 席位可根据 QNH 区间确定过渡高度层，在预设中使用 [TL]。

    内部变量 说明
    {trl} 数值，如 65
    {trl:###} 最少三位，如 065；文字和语音模板均适用
    {trl\|text} 词语形式，如 SIX FIVE

    在区间表中同时填写最低和最高 QNH 及对应高度层。点击 Add New 新增，选中后点击 Delete 删除。范围应依据 CAN 管制单位程序设置，避免遗漏或重叠。
