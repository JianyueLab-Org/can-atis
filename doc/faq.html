常见问题

数据文件在哪里？

Windows 默认：

%LOCALAPPDATA%\ceruleanavi.atis-for-can

主窗口或配置列表按 Ctrl+Shift+O 可打开。macOS / Linux 如果构建运行，具体位置取决于 .NET 的 LocalApplicationData 目录，再加 ceruleanavi.atis-for-can，不使用原版 org.vatsim.vatis。

路径 内容
AppConfig.json 用户设置，包含个人登录资料，不公开分享
Profiles 席位配置 JSON
VoicePacks 导入的语音包
Logs 运行日志

能用 VATSIM 账号登录 CAN 吗？

CAN 网络连接需要 CAN ID 和 CAN 网络密码。公共发布包不包含个人账号，也不会读取原版 vATIS 保存的账号。

为什么有原版音色列表，却不能合成？

列表是公开的名称与 ID。真正合成由原版远端服务完成并要求有效认证；模型不在客户端里。CAN 尚未部署面向所有用户的独立同款 TTS，显示列表不等于服务已开通。

有哪些语音方式？

可以编辑语音文本、人工录音或使用本地 WAV 语音包。在线 TTS 必须有可用服务。生成音频、在本机试听和通过网络发送是三个独立步骤。

FSD 在线就表示语音正常吗？

不表示。FSD 管理在线状态和文字情报；语音还需要音频生成、Python worker、Mumble 认证、频率频道和实际发送成功。

当前 worker 发完一段 PCM 后退出，持续循环播报尚待完善；依赖还是旧 pymumble，不能将 UDP 语音视为当前已交付能力。维护者应以真实接收端持续收听验证。

UDP 通了为什么没有声音？

服务器 UDP Ping 成功只表示探测可达，不表示客户端已完成加密音频协商或发送。应同时检查 TLS 控制连接、认证、频道、Opus 及客户端所用库版本。

为什么看不到其他管制员同步的字母？

原版共享席位依赖 ATIS Hub。CAN 当前未连接该 Hub，原版的共享订阅、自动同步及断线保留行为不能保证。

能导入原版配置吗？

可作为基础导入，但需核对频率、FAA / ICAO 格式、缩略语、数据源和语音配置。原版音色配置不会附带合成权限或模型。

为什么配置更新后本地修改消失？

如果配置带 updateUrl，远端更高版本会自动覆盖大多数本地内容；保留本地名称及 WAV 包选择。详见自动更新。

如何备份和分享？

使用配置导出功能；使用 WAV 包时导出 ZIP 带所需片段。备份个人数据可以自行保存数据目录，但公共分享仅使用已检查的配置和语音包，不含 AppConfig 或令牌。

离线能用什么？

可编辑配置、使用本地机场数据、输入 METAR 并测试本地 WAV 拼接。网络上线、获取天气 / D-ATIS 和在线 TTS 仍需相应服务。
